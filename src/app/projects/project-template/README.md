# Copyable project page

Copy this folder into a new project folder under `src/app/projects/`, then:

1. Rename the three `project-template` files and update the component class and selector in the TypeScript file.
2. Replace `projectType`, `projectName`, and `projectSubtitle` with the new project's details.
3. Add a route for the component in `src/app/app.routes.ts` and link to that route from the project card.
4. Put the project's video in `public/videos/` and update its source. Remove the video block if there is no video.
5. Replace the empty write areas with project text. Duplicate or remove sections as needed.

The component is a starter only and is not registered as a public route or shown in the project list.

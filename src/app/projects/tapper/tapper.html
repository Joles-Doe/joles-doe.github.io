Tapper

A classic arcade game rebuilt in C++ with SDL.

GH GitHub

Overview

Tapper started as a way to put my C++ skills into practice. I built a small game engine on top of SDL, then created an arcade game with it as a hands-on challenge.

Engine and object lifecycle

Taking inspiration from Unity, I designed game objects with update and draw functions that the engine calls each frame. I used shared pointers to manage object lifetime and remove objects from the engine hierarchy without hard-coded names.

Game objects

A shared base class with virtual update and draw functions let the engine work with different object types through the same interface.

What I learned

The project gave me practical experience with object-oriented design and memory management, and showed me how much easier development becomes when the engine and game are broken into clear parts.
